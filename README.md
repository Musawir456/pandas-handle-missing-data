# Handling Missing Data in Pandas

This repository focuses on handling missing data using **Pandas**, which is a critical step in data cleaning and preprocessing for data analysis and machine learning.

## Overview
Missing data is a common problem in real-world datasets. This repository demonstrates different techniques to identify, remove, and fill missing values efficiently using Pandas.

## Topics Covered
- What is Missing Data (NaN, None)
- Detecting Missing Values
  - `isnull()`
  - `notnull()`
  - `isnull().sum()`
- Removing Missing Data
  - `dropna()`
  - Row-wise & Column-wise deletion
  - Conditional deletion using `subset`
- Filling Missing Data
  - Fill with constant values
  - Fill with Mean
  - Fill with Median
  - Fill with Mode
- Forward Fill (`ffill`)
- Backward Fill (`bfill`)
- Replacing invalid values with NaN
